# Data Monster — Design Context

## Users

Analysts and business users at small-to-mid organizations who connect CSV/Parquet/Postgres data, query it with SQL, explore it visually, and build lightweight data pages. Desktop app (Tauri), used in focused daytime work sessions. The data is often financial or commercially sensitive — the interface must feel like a place where numbers are safe and correct.

## Brand Personality

**Quietly confident institution.** Three words: precise, institutional, trustworthy. The emotional goal: "I can make a decision based on what this screen tells me." Key attributes the design must project: accurate, finance, trust, insight, growth.

## Aesthetic Direction

- **Theme**: Light. Annual-report clarity — white paper, ink, and one deep green. Never dark-terminal cosplay.
- **Voice**: Ledger/finance editorial. A precision instrument, not a toy.
- **Type**: Spectral (display serif — annual-report gravitas) + Public Sans (body — institutional grotesk with excellent tabular figures). Geist Mono for SQL/code/data.
- **Color**: Ledger green (OKLCH hue ~158) as the single brand accent, used sparingly (60-30-10). Neutrals tinted toward the brand hue. Gold reserved as rare micro-accent (growth/profit connotation), never decorative.
- **Anti-references**: AI-slop cyan-on-dark, purple gradients, glassmorphism cards, copper warmth (previous identity), playful/toy-like illustration.

## Design Principles

1. **Numbers are sacred** — tabular figures everywhere data appears; alignment over decoration.
2. **One accent, used rarely** — green signals interactivity and truth; if everything is green, nothing is.
3. **Paper, not glass** — flat surfaces, hairline borders, crisp 2-4px radii. Shadows are subtle depth cues, never decoration.
4. **Editorial hierarchy** — serif display for section gravitas, grotesk for working UI, mono for data. No more than 5 type steps in app chrome.
5. **Restraint reads as confidence** — an institution doesn't shout. Whitespace and hairlines do the work color did before.
