API Reference

picasso.js

picasso.js is a charting library streamlined for building visualizations for the Qlik Sense Analytics platform. This reference documents all 112+ definitions including the entry function, components, scales, brushes, renderers, geometric types, and lifecycle hooks.

Entries

picassojsfunction

Entry point for creating picasso.js charts. Returns a picasso instance with chart creation and registry access.

Parameters

PropertyTypeDefaultDescription

cfg.logger.level required0 | 1 | 2 | 3 | 4—Log verbosity level (0=off, 4=debug)
cfg.styleobject—Default style overrides
