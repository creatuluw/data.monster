# Interview the user one question at a time with lettered multiple-choice options

## Guideline

When conducting any interview with the user (PRD, design, spec, scoping), ask questions **one at a time**, with multiple-choice answers labeled **A) B) C)…** (or numbered). Before the first question, give a short shared-context block (vocabulary, what was studied, where we already stand) so each question lands on common ground. It is fine to state a lean/recommendation for the options — but let the user pick.

## When it applies

Every interactive question-and-answer flow where the assistant gathers requirements or decisions from the user — e.g. `.prds/` PRD interviews, the central reusable-chart design interview (2026-09-15), wizard-style flows.

## Rationale

The user asked for this format explicitly at the start of the chart-design interview ("ask me all questions 1-by-1 using letters/numbers for multi choice responses"). Single lettered questions are answerable in one short reply, keep complex decisions from collapsing into wall-of-text answers, and make the chosen option unambiguous in the transcript (useful when the final decision gets recorded to docs/wiki later).
