Can D2 (d2lang.com) render interactive diagrams where elements can be selected or given behavior/links — and if not, what are the alternatives?

D2 natively supports exactly two interactivity features — tooltip (hover text) and link (click a shape → navigate to a URL). No selection, no click callbacks, no JS event binding. However, D2's SVG output is scriptable: shape names are recoverable from base64-encoded CSS classes (empirically verified by running the official @terrastruct/d2 WASM package), so custom selection/behavior can be layered on in a host page. If you need true interactivity out of the box, the alternatives are: Mermaid (the only DSL with JS click callbacks), interactive diagram libraries (Cytoscape.js, React/Svelte Flow, AntV X6, Rete.js, GoJS), or embeddable editors (Excalidraw, tldraw).

D2 natively: tooltip + link, nothing more

D2's own "Interactive" tour section lists exactly two features, unchanged since they shipped in v0.1.4 (Dec 2022). That release promised "much more in store for interactivity" — nothing more has landed in the docs in the years since.

  • tooltip: adds hover text (HTML <title> tags; no markdown; degrades to a numbered appendix on PNG export) verified — d2lang.com/tour/interactive
  • link: makes a shape clickable → navigates to an external URL (fragments with # must be quoted) verified — d2lang.com/tour/interactive
  • No click callbacks, event-handler keywords, or render-event API exist anywhere in the docs or repo verified (absence)
  • No selection state, no multi-select, no touch support for tooltips (open issue #897 since Feb 2023); links/tooltips can't carry custom labels (issue #1205) verified
  • Animations are passive loops (GIF board cycling, marching-ants dashes) — not user interaction; play.d2lang.com is "interactive" only as a source editor verified

The DIY escape hatch: D2's SVG is scriptable

A leaf agent installed the official @terrastruct/d2 npm package (WASM) and rendered diagrams live to check the output DOM. Shape identity is recoverable — but not the way blog posts claim.

  • Every shape renders as <g class="{base64url(shapeKey)}"><g class="shape">…</g></g>; connections encode (src -> dst)[0]. Decode from JS: atob(cls) verified empirically (ran @terrastruct/d2 v0.1.33 / D2 v0.7.0-HEAD)
  • The common claim "shape names appear as SVG id attributes" is false — deliberate XSS/id-collision safety verified (d2svg.go + security tests)
  • JS API: new D2() → compile(src) → render(diagram) → SVG string; isomorphic browser/Node; Go library also exists verified
  • So: querySelectorAll('g.shape') → decode parent class → attach your own click/selection handlers. Works, but the class scheme is de-facto stable, not a documented public contract — an upgrade could break it inferred
  • Deeper hook: the compiled IR (JSON) exposes shapes[].classes — custom classes can be injected between compile and render reported

The real answer: interactive diagram libraries

Every library below natively supports element selection + click/behavior binding — what D2 lacks, these have out of the box.

  • Cytoscape.js — click-select, box select, modifier multi-select, delegated cy.on('tap','node',…); MIT; vanilla, framework-agnostic verified
  • React Flow / Svelte Flow — elementsSelectable (default on), onNodeClick, onSelectionChange; MIT; one per framework verified
  • AntV X6 — graph editing engine: node:click/port:click/edge:click events, lasso selection, minimap; MIT verified
  • AntV G6 — analysis-oriented sibling, same event system; MIT reported
  • Rete.js — node-editor framework: selectableNodes, nodepicked; MIT; Svelte renderer plugin exists verified
  • JointJS — open core, but advanced selection/interaction tooling largely lands in commercial JointJS+ reported
  • GoJS — best built-in interaction polish (select, drag, undo); commercial, evaluation watermark reported
  • D3.js — raw selection.on("click",…) works, but selection state, node model, and links are all hand-built verified

D2's peer DSLs: only Mermaid goes further

  • Mermaid — the only text DSL with real JS click callbacks: click nodeId callback invokes a function on the hosting page; requires securityLevel: 'loose' (default strict disables it) and bindFunctions() after DOM insertion verified — mermaid.js.org
  • Graphviz — URL/href node attributes + native tooltip; pure SVG anchors, zero scripting — same tier as D2 verified
  • PlantUML — [[url{tooltip} label]] across ~8 diagram types; links inert in PNG output verified
  • Kroki (server-side rendering) kills scripted interactivity by construction: securityLevel can't be overridden per request; only native SVG anchors survive, and only when the SVG is inlined (not <img>) verified
  • Net: among DSLs, D2's tooltip+link ≈ Graphviz/PlantUML tier. Mermaid alone adds callbacks. Nothing in the DSL world gives selection state.

Embeddable diagram editors

  • tldraw — React SDK; editor.on('event') gives shape-level pointer targets, store.listen() for all mutations — richest programmatic attach; source-available, production requires a license key verified
  • Excalidraw — React component, MIT; onChange(elements, appState, files) + onLinkOpen; own JSON format; programmatic element API still beta verified
  • draw.io embed mode — iframe + postMessage gives lifecycle events (init/save/exit) but no per-shape selection/click events; only openLink forwarding; Apache-2.0 verified
  • maxGraph — maintained Apache-2.0 TypeScript successor to mxGraph; library-embed with full programmatic selection model verified
  • yFiles for HTML — fully programmatic graph/selection; closed-source commercial SDK reported

Tensions

Where branches disagree or where marketing and reality diverge — kept visible, not averaged away.

Tension

D2's homepage markets "Hover over shapes to learn more, or click through to another page" — which sounds rich, but resolves to exactly tooltip + external link (branch 1, high confidence). v0.1.4's Dec-2022 promise of "much more in store for interactivity" still hasn't landed in the docs.

Tension

Blog-level claims say D2 SVGs carry shape names as id attributes; the empirical run proved they're base64 classes, deliberately (XSS safety). The class scheme is de-facto stable but undocumented — DIY interactivity built on it has no compatibility contract (branch 2, high confidence on facts, medium on long-term stability).

Tension

"Open source" diverges sharply in the alternatives: tldraw is source-available but production needs a paid key; GoJS renders a watermark unlicensed; JointJS gates advanced selection tooling behind JointJS+; draw.io embed is Apache-2.0 but exposes no selection events. Assessment: for guaranteed-free interactivity, the safe set is Cytoscape.js, React/Svelte Flow, X6, Rete.js, Excalidraw, maxGraph (branches 3+5, high confidence).

Tension

Mermaid's click callbacks are real but fragile: dead under default strict securityLevel, in static exports, in GitHub, and in Kroki (branch 4, high confidence). The most-advertised DSL interactivity feature has the most deployment traps.
